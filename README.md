
# InterviewAI - AI-Powered Mock Interview Platform

## About the Project
InterviewAI is a Python-based web application built using Streamlit. It helps students practice interview questions, evaluate their answers, identify weak areas, and improve their interview preparation.

## Features
- Mock interview question practice
- Automated answer evaluation and feedback
- Score-based performance analysis
- Example answers and improvement suggestions for weak answers
- Resume upload and skill extraction
- Resume and Job Description (JD) matching
- Missing skills identification
- Personalized learning roadmap
- Final interview report
- Performance dashboard and score chart

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- Natural Language Processing (NLP)
- TF-IDF and Cosine Similarity
- PDF processing libraries

## How to Run the Project

1. Clone or download the project.
2. Open the project folder in the terminal.
3. Install the required dependencies:

   `pip install -r requirements.txt`

4. Run the application:

   `streamlit run app.py`

5. Open the local URL displayed in the terminal.

## Project Objective
The objective of InterviewAI is to help students prepare for job interviews by providing automated feedback, resume-job matching, skill gap analysis, and personalized learning suggestions.
